# 단순여행 Design System

> 여행/모임 일정을 팀 단위로 쉽고 직관적으로 관리하는 웹 서비스를 위한 디자인 시스템 문서입니다.
> 이 문서는 프론트엔드 구현 시 그대로 참조하는 것을 목표로 하며, 모든 토큰은 실제 사용 가능한 값으로 작성되어 있습니다.

---

## 0. 서비스 개요

- **서비스명**: 단순여행
- **핵심 가치**: 여행/모임 일정을 "프로젝트" 단위로 묶어, 캘린더와 할 일 목록을 한 화면에서 직관적으로 확인하고 공유한다.
- **핵심 기능**: 팀 공간(프로젝트) 생성, 팀별 할 일(일정) 목록, 일정 등록 모달, 캘린더 뷰, 마이페이지, 로그인/회원가입, 다크모드
- **타겟 사용자**: 함께 여행/모임 일정을 공유하는 20~30대 친구 모임, 소모임. 모바일 사용 비중이 높지만 데스크톱도 함께 지원.
- **참고 서비스**: 피클플러스(발랄하고 비비드한 포인트 컬러), 뱅크샐러드(민트 기반의 신뢰감 있는 미니멀 UI), 카카오페이(단순하고 명확한 정보 위계)

---

## 1. 디자인 원칙

1. **한눈에 보이는 일정 (Glanceable First)**
   여행 일정은 정보가 많아지기 쉬운 도메인입니다. 캘린더·리스트 어디서든 "오늘 뭐 하지?"가 3초 안에 파악되도록, 정보 밀도보다 시인성을 우선합니다.

2. **미니멀 + 한 스푼의 발랄함 (Minimal but Playful)**
   기본 UI는 뱅크샐러드처럼 여백과 중립톤 위주로 차분하게 구성하되, 포인트 컬러(비비드 코랄)를 CTA·강조 요소에만 집중 사용해 "귀여운" 인상을 만듭니다. 컬러를 아끼는 것이 오히려 포인트를 살립니다.

3. **함께 쓰는 도구로서의 명확성 (Clarity for Shared Use)**
   여러 명이 함께 보는 팀 공간이므로, 누구 일정인지·무슨 상태인지가 색상/아이콘만으로도 즉시 구분되어야 합니다. 모호한 회색보다 명확한 시맨틱 컬러를 우선합니다.

4. **엄지 영역 우선 설계 (Thumb-friendly)**
   모바일 사용 비중이 높으므로, 일정 등록 같은 핵심 액션은 화면 하단/엄지가 닿는 위치에 배치하고 터치 타겟은 최소 44px를 보장합니다.

5. **라이트/다크 동등 대우 (Dark Mode as First-class)**
   다크모드가 부가 기능이 아니라 기본 기능이므로, 모든 컬러 토큰은 라이트/다크 쌍으로 정의하고 별도 검수합니다.

## 2. 컬러 토큰

### 2.1 Primary — 선셋 코랄 (Sunset Coral)
여행의 설렘과 귀여운 인상을 담당하는 메인 포인트 컬러. CTA 버튼, 활성 탭, 오늘 날짜 강조, 로고 등 "가장 눈에 띄어야 할 곳"에만 사용합니다.

| 토큰 | Light | Dark | 사용 맥락 |
|---|---|---|---|
| `color-primary-50` | `#FFF1EC` | `#2A1A16` | 코랄 배경 위 서브 텍스트/배지 배경 |
| `color-primary-100` | `#FFDBCE` | `#3D251E` | 호버 시 은은한 배경 |
| `color-primary-300` | `#FF9C7D` | `#FF9C7D` | 보조 강조, 아이콘 |
| `color-primary-500` | `#FF6F4D` | `#FF7A56` | **메인 컬러.** Primary 버튼, 활성 상태, 로고 |
| `color-primary-600` | `#F0552E` | `#FF5A32` | Primary 버튼 hover/pressed |
| `color-primary-700` | `#C13F1F` | `#D6421F` | Primary 버튼 disabled 텍스트 대비용(다크에서만 사용) |

### 2.2 Secondary — 민트 (Calm Mint)
뱅크샐러드에서 착안한 보조 컬러. 캘린더의 "완료" 표시, 보조 버튼, 정보성 배지 등 코랄과 부딪히지 않는 차분한 보조 역할.

| 토큰 | Light | Dark | 사용 맥락 |
|---|---|---|---|
| `color-secondary-50` | `#EAFBF6` | `#0F211D` | 보조 배경 |
| `color-secondary-300` | `#8FE3CB` | `#4FBE9E` | 보조 아이콘, 그래프 |
| `color-secondary-500` | `#2FBF8F` | `#3ECB9B` | Secondary 버튼, 완료 상태 표시 |
| `color-secondary-600` | `#22A97A` | `#2FB587` | Secondary 버튼 hover |

### 2.3 Neutral (Grayscale)
차갑지 않은 웜 그레이 톤으로 "미니멀하지만 딱딱하지 않은" 인상을 유지합니다.

| 토큰 | Light | Dark | 사용 맥락 |
|---|---|---|---|
| `color-neutral-0` | `#FFFFFF` | `#121212` | 최상위 배경(카드/시트) |
| `color-neutral-50` | `#FAF9F7` | `#181818` | 페이지 배경 |
| `color-neutral-100` | `#F1EFEC` | `#1F1F1F` | 구분 배경, 비활성 필드 |
| `color-neutral-200` | `#E4E1DC` | `#2A2A2A` | 보더, 디바이더 |
| `color-neutral-400` | `#B3AEA6` | `#5C5C5C` | placeholder, disabled 텍스트 |
| `color-neutral-600` | `#7A756C` | `#9A9A9A` | 보조 텍스트(caption, 설명) |
| `color-neutral-800` | `#4A463F` | `#D4D4D4` | 서브 헤딩 |
| `color-neutral-900` | `#252220` | `#F5F5F5` | 본문/헤딩 기본 텍스트 |

### 2.4 Semantic

| 토큰 | Light | Dark | 사용 맥락 |
|---|---|---|---|
| `color-success` | `#2FBF8F` | `#3ECB9B` | 저장 완료, 일정 확정 토스트 |
| `color-warning` | `#F5A623` | `#F7B84D` | 일정 임박, 미확정 상태 |
| `color-error` | `#E5484D` | `#F2696D` | 폼 유효성 오류, 삭제 확인 |
| `color-info` | `#4C8DFF` | `#6FA1FF` | 안내 배너, 신규 기능 툴팁 |

### 2.5 접근성 대비 참고
- `color-primary-500`(#FF6F4D) 위 흰 텍스트는 대비 3.2:1 → **큰 텍스트/아이콘 전용**. 본문 텍스트에는 `color-primary-600` 이상 사용.
- 본문 텍스트(`neutral-900` on `neutral-0`)는 대비 15:1 이상으로 WCAG AA/AAA 모두 충족.

## 3. 타이포그래피

### 3.1 폰트 패밀리
```css
font-family: "Pretendard", -apple-system, BlinkMacSystemFont,
  "Apple SD Gothic Neo", "Segoe UI", system-ui, sans-serif;
```
- Pretendard: 둥근 인상과 높은 가독성으로 "귀엽지만 신뢰감 있는" 톤에 적합, 웹폰트 로드 실패 시 시스템 산세리프로 자연스럽게 폴백.
- 숫자(날짜, 시간) 강조가 잦으므로 `font-variant-numeric: tabular-nums;`를 캘린더/리스트 숫자에 적용 권장.

### 3.2 타입 스케일

| 토큰 | 크기 (px/rem) | 줄간격 | 굵기 | 용도 |
|---|---|---|---|---|
| `text-h1` | 32px / 2rem | 1.3 | 700 | 페이지 최상위 타이틀 (거의 미사용, 랜딩 전용) |
| `text-h2` | 26px / 1.625rem | 1.35 | 700 | 프로젝트(팀 공간) 타이틀 |
| `text-h3` | 22px / 1.375rem | 1.4 | 600 | 섹션 타이틀 (캘린더 월 표시, 마이페이지 섹션) |
| `text-h4` | 18px / 1.125rem | 1.4 | 600 | 카드 타이틀, 모달 타이틀 |
| `text-h5` | 16px / 1rem | 1.5 | 600 | 리스트 아이템 타이틀 |
| `text-body` | 15px / 0.9375rem | 1.6 | 400 | 기본 본문 |
| `text-body-sm` | 13px / 0.8125rem | 1.55 | 400 | 보조 설명, 폼 헬퍼 텍스트 |
| `text-caption` | 12px / 0.75rem | 1.4 | 500 | 뱃지, 타임스탬프, 태그 |
| `text-button` | 15px / 0.9375rem | 1 | 600 | 버튼 라벨 |

| `space-5` | 20px | 섹션 내부 여백 |
| `space-6` | 24px | 섹션 간 여백 |
| `space-8` | 32px | 페이지 상하 여백 |
| `space-10` | 40px | 모달 padding (데스크톱) |

### 4.2 그리드 & 브레이크포인트
| 브레이크포인트 | 범위 | 컬럼 | 거터 | 컨테이너 max-width |

## 5. 컴포넌트 가이드

### 5.1 버튼

| Variant | 배경 | 텍스트 | 사용처 |
|---|---|---|---|
| Primary | `color-primary-500` | `#FFFFFF` | 일정 등록, 프로젝트 생성 등 핵심 CTA (화면당 1개 원칙) |
| Secondary | `color-secondary-500` | `#FFFFFF` | 완료 처리, 참여하기 등 보조 확정 액션 |
| Ghost | `transparent` (보더 `neutral-200`) | `neutral-900` | 취소, 뒤로가기 등 저강도 액션 |

상태별 스타일:
- **Default**: 위 표 기준
- **Hover**: 배경을 8% 어둡게 (`color-mix(in srgb, base 92%, black)`), transition `120ms ease-out`
- **Pressed**: 배경을 14% 어둡게 + scale(0.98)
- **Disabled**: 배경 `neutral-200`(다크: `neutral-800`), 텍스트 `neutral-400`, 클릭 이벤트 없음, opacity 변화 대신 색상으로만 구분(색약 사용자 고려)

크기: `sm`(32px 높이, 모바일 인라인 버튼) / `md`(44px, 기본) / `lg`(52px, 모바일 하단 고정 CTA)

### 5.2 인풋
- 높이: 44px (모바일 터치 타겟 기준)
- 기본 보더: `1px solid color-neutral-200`, radius `10px`
- Focus: 보더 `color-primary-500` + `box-shadow: 0 0 0 3px color-primary-100`
- Error: 보더 `color-error`, 하단에 `text-body-sm` + `color-error`로 헬퍼 텍스트
- Placeholder: `color-neutral-400`

### 5.3 카드
- 배경 `color-neutral-0`, radius `16px`, padding `space-4`
- 그림자: `0 2px 8px rgba(0,0,0,0.06)` (다크모드에서는 그림자 대신 `1px solid color-neutral-200` 보더로 대체 — 다크 배경에서 그림자는 시인성이 낮음)
- 일정 카드는 좌측에 `4px` 두께의 컬러 바로 프로젝트/카테고리 구분

### 5.4 모달 (일정 등록 모달 기준)
- 데스크톱: 중앙 정렬, max-width `480px`, radius `20px`, padding `space-10`
- 모바일: 하단 시트(bottom sheet) 형태로 전환, 상단 radius만 `20px`, 드래그 핸들 바 표시
- 오버레이: `rgba(37,34,32,0.45)` (라이트) / `rgba(0,0,0,0.6)` (다크)
- Primary 버튼(저장/등록)은 항상 모달 하단 우측(데스크톱) 또는 하단 고정 풀와이드(모바일)

### 5.5 다크모드 전환 규칙
- 배경/텍스트는 반전하되, Primary 컬러 자체는 채도를 유지하고 명도만 살짝 올려(`#FF6F4D` → `#FF7A56`) 어두운 배경에서도 선명하게 보이도록 조정
- 다크모드에서 그림자 대신 보더 사용 (5.3 참고)

## 6. 아이콘 & 일러스트 톤

- **아이콘 스타일**: 1.5px stroke 기반의 라운드 아웃라인 아이콘(rounded line icon). 채움(filled) 아이콘은 활성 탭 등 "선택됨"을 나타낼 때만 예외적으로 사용.
- **일러스트 톤**: 피클플러스류의 플랫하고 발랄한 일러스트 방향. 빈 상태(empty state) 화면(예: "아직 등록된 일정이 없어요")에 코랄/민트 2색 조합의 미니 일러스트 사용 권장.
- 사진(여행지 이미지 등)을 쓸 경우 카드 radius와 동일한 `16px` 라운드 처리로 통일감 유지.

---

## 7. 접근성 기준 (최소 요건)

1. **색 대비**: 본문 텍스트 대비 4.5:1 이상, 큰 텍스트(24px 이상 또는 19px bold 이상)는 3:1 이상 (WCAG AA)
2. **포커스 스타일**: 모든 인터랙티브 요소는 키보드 포커스 시 `box-shadow: 0 0 0 3px color-primary-100` 형태의 명확한 포커스 링 표시 (아웃라인 제거 금지)
3. **터치 타겟**: 최소 44×44px (모바일 버튼/아이콘 버튼 공통)
4. **색상 단독 전달 금지**: 일정 상태(완료/임박/지연 등)는 색상 + 아이콘 또는 텍스트 라벨을 함께 사용
5. **다크모드 명도 대비**: 다크 배경(`#121212`) 위 기본 텍스트(`#F5F5F5`)는 대비 14:1 이상 확보
