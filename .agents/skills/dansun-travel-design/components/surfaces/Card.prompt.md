The default surface for grouped content; `muted` variant is the app's tappable list card.

```jsx
<Card accentColor="var(--brand)">
  <CardTitle>제주 3박 4일</CardTitle>
  <CardDescription>친구 5명 · 11월 12일 출발</CardDescription>
</Card>
```

In dark mode the shadow is replaced by a 1px border (see `--card-dark-border`).
